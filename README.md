# Proyek Analisis Data Dengan Python 📊

Selamat datang di repositori **Proyek Analisis Data Dengan Python**! Proyek ini bertujuan untuk memberikan wawasan mendalam melalui analisis data menggunakan bahasa pemrograman Python. Di sini, Anda akan menemukan berbagai alat dan teknik yang digunakan untuk menganalisis dan memvisualisasikan data.

---

## Fitur Utama ✨

- **Analisis Data**: Menggunakan pustaka Python seperti Pandas dan NumPy untuk analisis data yang efisien.
- **Visualisasi Data**: Membuat visualisasi interaktif dengan Streamlit untuk memudahkan pemahaman data.
- **Dashboard Interaktif**: Menyediakan dashboard yang dapat diakses untuk menampilkan hasil analisis secara real-time.

---

## Setup Environment 🛠️

Untuk memulai, Anda perlu menginstal semua dependensi yang diperlukan. Anda dapat melakukannya dengan menjalankan perintah berikut:

```bash
pip install -r requirements.txt
```

---

## Setup Environment - Shell/Terminal 💻

Ikuti langkah-langkah berikut untuk menyiapkan lingkungan proyek Anda:

```bash
mkdir proyek_analisis_data
cd proyek_analisis_data
pipenv install
pipenv shell
pip install -r requirements.txt
```

---

## Run Streamlit App 🚀

Setelah semua terinstal, jalankan aplikasi Streamlit dengan perintah berikut:

```bash
streamlit run dashboard.py
```

---

## Struktur Proyek 📁

- `dashboard.py`: Skrip utama untuk menjalankan aplikasi Streamlit.
- `requirements.txt`: Daftar semua dependensi yang diperlukan untuk proyek ini.
- `data/`: Folder untuk menyimpan dataset yang digunakan dalam analisis.
